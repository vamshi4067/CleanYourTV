# Cricket Legends configuration

Optional configuration for the bundled customized Home. The Java customization and assets are in `launcher/`; this JSON alone does not reproduce them in an unmodified upstream launcher.

See [customization](../../docs/CUSTOMIZATION.md) and [screenshots](../../docs/SCREENSHOTS.md). No personal greeting, location, device addresses, or saved account state is included. Idle photo/clock wallpaper mode is disabled.
