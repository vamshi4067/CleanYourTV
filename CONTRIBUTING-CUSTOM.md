# Contributing to this customized build

Describe the affected screen, Android/TV version, expected navigation, and actual result. Include only redacted screenshots. Keep changes focused; preserve a working Home, source attribution, and private-data exclusions.

Run the privacy checker and the relevant Android unit/lint/build checks in [architecture](docs/ARCHITECTURE.md). For navigation changes, test row edges, rapid presses, opening/closing panels, and physical remote behaviour. Never submit TV backups, signing keys, ADB keys, account information, or `.env` files.

The original `CONTRIBUTING.md` describes contributions to the upstream project. This derivative has its own expanded features and media. Send changes for this customized launcher to this repository, and respect separate rights for media in [MEDIA-NOTICE.md](MEDIA-NOTICE.md).
