# Reporting a security issue

Do not publish credentials, device dumps, ADB keys, account screenshots, or personal identifiers in an issue. For a sensitive vulnerability, use this repository's private vulnerability-reporting channel if enabled; otherwise contact its owner privately through an available GitHub contact route. Do not send customized-build reports to the upstream maintainer unless the problem is reproduced upstream.

For an exposed credential, revoke/rotate it first, then remove it from every published commit. Removing only the current file does not remove history. See [privacy documentation](docs/PRIVACY.md).
